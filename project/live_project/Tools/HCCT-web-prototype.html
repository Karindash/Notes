COGNITIVE SYSTEMS / RESEARCH SPACEVERSION 0.1
An evolving taxonomy of human capability

Understand the capabilities behind human decisions.

HCCT is an exploratory framework for mapping how people perceive, process, remember, reason, decide, act, learn, and adapt across different situations.

Working definition: Human cognitive capability is the set of mental and behavioral capabilities through which a person receives and interprets stimuli, transforms information, evaluates situations, makes decisions, executes actions, learns, and adapts.
Framework architecture

From foundational operations to real-world abilities

Start with broad operations, decompose them into observable sub-capabilities, then map how they combine in everyday tasks.

01 / PRIMITIVES

Primitive operations

Candidate foundational functions such as perception, attention, memory, reasoning, and adaptation.

02 / COMPONENTS

Sub-capabilities

More specific capabilities that can be defined and investigated, such as working memory or causal reasoning.

03 / IN PRACTICE

Composite abilities

Real-world performance that emerges from multiple capabilities working together, such as tactical decision-making.

Design principles

How we will keep the model useful

Observable

Every capability should eventually connect to evidence, behavior, or task performance.

Distinct where possible

Overlaps are documented rather than hidden. Categories must earn their place.

Non-hierarchical

No capability is automatically superior. A profile is multidimensional, not a single rank.

Important: HCCT is currently conceptual. Its categories, boundaries, and assessment methods have not been scientifically validated.
